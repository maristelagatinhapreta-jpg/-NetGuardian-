# 🛡️ NetGuardian

Sistema de Monitoramento de Rede desenvolvido com Python e Flask.

O NetGuardian é uma aplicação web criada para monitorar informações básicas da rede e do computador através de uma interface web moderna e intuitiva.

---

## 📋 Recursos

✅ Dashboard Web

✅ Exibição do Nome do Computador

✅ Exibição do Endereço IP Local

✅ Detecção do Sistema Operacional

✅ Detecção da Versão do Sistema

✅ Interface Responsiva

✅ Desenvolvido em Python + Flask

---

## 🖥️ Demonstração

O sistema exibe informações do computador em tempo real:

- Status Online
- Nome do Host
- Endereço IP
- Sistema Operacional
- Versão do Sistema

## 🚀 Instalação

### Clonar o projeto

```bash
git clone https://github.com/SEU-USUARIO/NetGuardian.git
```

Entrar na pasta:

```bash
cd NetGuardian
```

---

## 📦 Instalar Dependências

```bash
pip install -r requirements.txt
```

Ou:

```bash
pip install flask
pip install psutil
pip install scapy
```

---

## ▶️ Executar Aplicação

Acesse a pasta dashboard:

```bash
cd dashboard
```

Execute:

```bash
python app.py
```

Saída esperada:

```text
* Running on http://127.0.0.1:5000
```

---

## 🌐 Abrir no Navegador

Acesse:

